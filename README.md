**Project Title**
>Automation Testing of HR Management Web Application https://opensource-demo.orangehrmlive.com

**Overview**
>This Project automates critical HR Management website functionalities using selenium WebDriver and Pytest framework following
the Page object model (POM) design pattern

**Features**
* Selenium WebDriver automation
* Pytest Framework
* Data Driven Testing
* Page Object Model(POM) 
* Explicit Waits
* Exception Handling
* Dynamic element Handling
* Pytest HTML Reports
* Reusable BasePage methods
* Github Actions CI/CD integration

**Tech Stack**
* Python
* Selenium
* Pytest
* Pytest HTML
* Github Actions

**Test Scenarios Covered**
* Login Button Validation
* Menu Navigation Validation
* valid login test 
* Invalid login test
* Logout functionality
* Create user

**Framework Design**
* Page Object Model
* Reusable BasePage utilities
* Explicit wait strategy
* Dynamic element handling
* Exception handling

**Installation**
> git clone <https://github.com/Rameshraj2000/QA-Automation-Guvi-HR-Management-Web-Application.git>
> CD Project2
> pip install -r requirements.txt

**Run Tests**
>pytest

**Generate HTML Report**
> pytest --html=reports/report.html --self-contained-html

**CI/CD**
**Github Actions pipeline automatically**
* Install dependencies
* Runs test suite
* generate reports

**Challenges Solved**
* Dynamic Dropdown
* Hidden Element Section
* Synchronization issues
* Javascript click fallback 
* Dynamic Dialog Box rendering
* Explicit wait optimization
